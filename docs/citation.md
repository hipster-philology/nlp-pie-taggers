# Citation

## Pie Extended

If you use Pie Extended in your work, please cite it:

```bibtex
@software{thibault_clerice_2020_3883590,
  author       = {Clérice, Thibault},
  title        = {Pie Extended, an extension for Pie with pre-processing and post-processing},
  month        = jun,
  year         = 2020,
  publisher    = {Zenodo},
  doi          = {10.5281/zenodo.3883589},
  url          = {https://doi.org/10.5281/zenodo.3883589}
}
```

The DOI [10.5281/zenodo.3883589](https://doi.org/10.5281/zenodo.3883589) always points to the latest version.
GitHub also reads the file [`CITATION.CFF`](https://github.com/hipster-philology/nlp-pie-taggers/blob/main/CITATION.CFF)
of the repository: use the *Cite this repository* button to get other formats (APA, BibTeX...).

## The models

Pie Extended brings the models of other people together, and **they** have to be credited too. Each model of
{doc}`models` has a *More* link to its documentation or its publication: please cite it when you use the model. In
particular:

- **Armenian** (`hy_hye`, `hy_hyw`, `hy_xcl`): Vidal-Gorène, Tomeh and Khurshudyan, models presented at the NLP4DH
  workshop of EMNLP 2024 ([ACL Anthology 2024.nlp4dh-1.42](https://aclanthology.org/2024.nlp4dh-1.42/));
- **Ancient Greek with GreCy** (`grc_grecy`): [greCy](https://github.com/jmyerston/greCy) by Jacobo Myerston, see
  the page of the project for the reference to cite;
- the **treebanks** the Armenian models and the Classical Armenian clitic segmenter rely on are the
  [Universal Dependencies](https://universaldependencies.org/) ones, with their own licenses (see {doc}`models`).
